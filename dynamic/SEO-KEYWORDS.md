# SEO Keyword Research Sabor Street Kitchen

## Primary keywords (high intent, used in <title> and H1 tags)

- tacos Merewether
- Mexican food Newcastle NSW
- street food Merewether NSW
- taco pickup near me
- Merewether restaurants

## Secondary / long-tail keywords (used in meta descriptions and body copy)

- late night tacos Newcastle
- quesabirria Newcastle NSW
- order tacos online Merewether
- best tacos near Merewether Beach
- Mexican street food catering Newcastle

## On-page SEO techniques applied

- Unique `<title>` and meta description per page, generated dynamically in `includes/header.php`
- Single `<h1>` per page matching the primary keyword for that page (e.g. "Build Your Order" on menu.php, "Our Story" on about.php)
- Descriptive, keyword-relevant `alt` text on every image (e.g. "Carne Asada Tacos — Tacos" rather than "image1.jpg")
- Semantic heading hierarchy (h1 → h2 → h3) instead of skipping levels or using headings purely for styling
- Human-readable URLs (`menu.php`, `contact.php`) rather than query-string-only routes
- `robots.txt` and `sitemap.xml` provided so search engines can crawl and index all public pages
- Open Graph tags (`og:title`, `og:description`, `og:type`) for better link previews when shared on social media
- Canonical URLs set per page to avoid duplicate-content issues

## Notes

Keyword choices are based on the business's real assigned location (Merewether NSW 2291) and category
(street-food/Mexican-inspired restaurant), reflecting how a real customer nearby would plausibly search.
